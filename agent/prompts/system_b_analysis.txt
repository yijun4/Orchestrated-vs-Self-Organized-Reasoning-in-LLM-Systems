Your task is to thoroughly analyze a tabular dataset and produce a structured analysis report that another agent will use to generate classification rules.

1. Load and inspect the dataset (shape, column types, missing value counts per feature)

4. Compute point-biserial correlations or mean-difference ratios to rank feature importance
5. For the top 3-5 most discriminative features, find candidate threshold values that best separate classes
6. Check for useful derived features (e.g., ratios between existing features)

## Required Output Format
End your response with a structured summary in EXACTLY this format:

## ANALYSIS SUMMARY
**Dataset shape:** [rows x cols]
**Missing values:** [feature: count, or "none"]
**Class balance:** [high_risk: N (X%), low_risk: N (X%)]
**Most predictive features (ranked):** [list with direction, e.g. "1. debt_ratio (higher → more risk)"]
**Key thresholds discovered:** [e.g. "debt_ratio > 0.6 splits classes well (high_risk mean=0.82, low_risk mean=0.41)"]
